# Pokémon Explorer

A responsive React-based app for browsing, filtering, and searching the first 150 Pokémon using the [PokéAPI](https://pokeapi.co/). Built with Tailwind CSS and modern component architecture.

## 🚀 Features

- 🔍 Search Pokémon by name
- 🧪 Filter Pokémon by type
- 📦 Fetches real data from PokéAPI
- 💅 Beautiful UI with Tailwind CSS
- 🔄 Responsive design for mobile & desktop
- ⚛️ Modular, component-based architecture

- **React + Vite** – Frontend library
- **Tailwind CSS** – Utility-first styling
- **Lucide Icons** – Icon set
- **PokéAPI** – Data provider

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/iamnirusan/Pokemon-Explorer.git
   cd pokemon-explorer
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
